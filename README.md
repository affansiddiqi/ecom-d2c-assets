# ecom-d2c-assets

Purely temporary public hosting for rendered Reels before Instagram fetches
them via the Content Publishing API. Files get pushed here right before
publish, then deleted right after Instagram has ingested them -- this repo
should almost always be empty. Same mechanism as `city-reels`
(public_assets_base -> raw.githubusercontent.com), kept as a separate repo
so ecom-d2c's actual business logic stays private.
